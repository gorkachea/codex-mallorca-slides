# Hackathon Codex · Intro

Slides con [Slidev](https://sli.dev) (Markdown + Vue).

```bash
npm install
npm run dev      # presentar (abre http://localhost:3030)
npm run export   # PDF
```

- `slides.md`: las slides. Cada `---` es una slide; las notas del orador van en `<!-- -->`.
- `styles/index.css`: colores y tipografía.
- Animaciones: `v-click` (aparece al hacer clic), `v-motion` (entrada animada), `v-mark` (subrayados/tachados).
- Iconos: `<logos-github-icon />`, `<ph-laptop-duotone />`… buscar en [icones.js.org](https://icones.js.org) (colecciones `logos` y `ph`).
- Vista de presentador con notas: `http://localhost:3030/presenter`.

`GUIA-PREPARACION.md`: guía para mandar a los asistentes de Luma.
