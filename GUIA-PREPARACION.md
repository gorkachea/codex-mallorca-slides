# 🛠️ Prepárate para el Hackathon de Codex

Haz esto antes del jueves para llegar listo. Solo tienes que instalar Codex y pegarle un mensaje: **Codex se encarga del resto**.

---

## 1. Instala Codex

1. Descarga la app de Codex en **[openai.com/codex](https://openai.com/codex)**.
2. Ábrela e inicia sesión con tu cuenta de **ChatGPT**.

## 2. Pega este mensaje en Codex

```
Hola Codex. El jueves voy a un hackathon de Codex y quiero dejar mi ordenador listo para construir y publicar una web o una app. Guíame paso a paso:

1. Comprueba qué tengo instalado y añade lo que falte: Git, Node.js (LTS), la CLI de GitHub (gh) y la CLI de Vercel.
2. Ayúdame a crear una cuenta en GitHub si no tengo e inicia sesión con `gh auth login`.
3. Ayúdame a crear una cuenta en Vercel con mi GitHub e inicia sesión con `vercel login`.
4. Al final, confírmame que todo está listo.
```

Si algo se te atasca, lo resolvemos el día del evento.

## Qué traer

- 💻 Portátil con Codex instalado
- 🔌 Cargador

¡Nos vemos el jueves! 🚀
